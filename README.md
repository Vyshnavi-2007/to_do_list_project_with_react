# 📋 Task Dashboard

A modern and responsive To-Do List application built using **React** and **Vite**. The application allows users to manage daily tasks through a clean, interactive, and user-friendly interface.

---

## ✨ Features

- 🔐 Login Page
- ➕ Add New Tasks
- ✅ Mark Tasks as Completed
- 🗑️ Delete Tasks
- 📊 Progress Tracker
- 📅 Current Date Display
- 💬 Random Motivational Quotes
- 🎨 Glassmorphism UI
- 📱 Responsive Design

---

## 🛠️ Technologies Used

- React.js
- CSS3
- React Router DOM
- Vite

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/task-dashboard.git
```

Navigate to the project:

```bash
cd task-dashboard
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
