# Task Dashboard

A modern and responsive To-Do List application built using **React** and **Vite**. The application allows users to manage daily tasks through a clean, interactive, and user-friendly interface.

---

## Features

- Login Page
- Add New Tasks
- Mark Tasks as Completed
- Delete Tasks
- Progress Tracker
- Current Date Display
- Random Motivational Quote
- Persistent Task Storage using Local Storage
- Glassmorphism UI
- Responsive Design

---

## Local Storage

The application uses the browser's **Local Storage API** to persist user data.

### Functionality

- Tasks are automatically saved whenever a task is added, completed, or deleted.
- Saved tasks are restored automatically when the application is reopened.
- Users can refresh the page or close the browser without losing their task list.
- No backend server or database is required for data persistence.

**Storage Key**

```text
tasks
```

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/task-dashboard.git
```

Navigate to the project:

```bash
cd task-dashboard
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
